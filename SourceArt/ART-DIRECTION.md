# 奶油粉工作室 · Soft 3D

本轮根据用户提供的工作室图片重做模型，借鉴 https://jelly.scottsun.io/ 实际页面可见的窗格反射、圆润轮廓、木质环境与温柔光照。采用原创动画电影式 3D 美术方向。

## 模型

- 连续的左右手皮肤网格：收细的手腕、饱满掌背、分开的四指、斜向拇指和浅指节凹纹。
- 十个独立 UV 甲面：圆弧甲根、横向 C 弧，运行时保持甲形、长度、宽度、建构、UV 绘画与饰品编辑。
- 奶油色罗纹袖口、粉色毛衣袖。
- 花朵标记的圆角方瓶、浅木托架、空心圆拱固化灯、爱心陶瓷盘、花瓣花器与雏菊、粉色锉条和木棒。
- 137 个网格对象；源文件保留完整场景、材质、灯光和相机，可继续在 Blender 编辑。

## 实时材质

原生 Built-in Standard 光照；`SoftSurface.shader` 使用顶点遮蔽、轻微暖色包裹光、棉织纹和木纹。皮肤效果是实时近似的柔和散射。甲油保留原来的分层透色、猫眼、镜面、哑光与笔迹，增加了程序生成的窗格和柔光箱环境反射。颜色和光照在 Unity 实机中检查。

Blender 使用 Cycles 预览；Unity 使用实时阴影和环境反射，因此两者有渲染差异。当前手部为静态风格化模型，整手照灯通过平移完成。

## 再生成

运行 `build_atelier.py` 会重建本文件夹中的 `指间诗工作室.blend`，并输出工程 `Assets/NailAtelier/Art/` 的 FBX 和 JSON。Unity 原生 Prefab 使用 JSON，以便没有本机 Blender 的用户也可以运行游戏。

JSON 坐标为 `(Blender X, Blender Z, Blender Y)`；三角形绕序随坐标系转换。UV 甲面在 Unity 导入时合并共享顶点，使运行时修改后仍能生成连续的平滑法线。避免单独更改坐标符号、绕序或相机朝向。
