# 纤长女生 CG 手 · Unity 同步

本目录的 `指间诗工作室-纤长女生CG手-间距修正版.blend` 来自用户确认的三视图重建版本。已包含修正后的手腕与袖口、拉开的器具间距和独立甲面；原始 Blender 文件保留。贴图和参考图打包在 blend 中。

使用 Blender 后台运行本目录 `export_cg_hands.py`，会导出项目 Art 目录中的 FBX、网格 JSON 与三张贴图。脚本仅修改内存中的场景，不保存覆盖源 blend。实际输入文件的 SHA-256、对象及顶点数量见 `unity-export-report.json`。

Unity 使用既有网格 JSON 导入管线。菜单「指间诗 → 同步 Blender 模型（保留当前场景）」更新网格、材质、预制体和锚点，保留资产 GUID；不会新建或覆盖当前场景。旧的「生成 Blender 模型与可玩场景」仍会重建场景，仅供有意重建时使用。

运行时手部减少约一半三角面，保留 UV 与轮廓；十个甲面使用各自贴合指尖的 24×40 UV 网格。`FittedNailSurface` 在此网格上采样甲形、宽度、延长和装饰位置，拇指使用独立三维方向，避免旧的平面甲床重建破坏贴合。

验证：137 个网格、114,943 顶点、216,036 三角面、10 个完整甲面；1,040 个甲面接触采样未发现超过 0.002 场景单位容差的穿透。Windows 运行时通过 373 项交互检查、0 错误。WebGL 实际验证加载、三维选指、改色和杏仁甲形；截图及报告见项目 `Verification/`。这些采样和交互验证不等于穷举所有极端参数；手机性能尚未实测。
